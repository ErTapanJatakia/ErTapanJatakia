# Security Policy

## Scope

This repository contains the public GitHub profile README and related profile materials for Er. Tapan Jatakia. Security reports are welcome for vulnerabilities or unsafe behaviour introduced by files, links, embedded content, or repository configuration maintained here.

This is a profile/documentation repository, not a software product or security-response service. There is no service-level agreement, guaranteed response time, or bug-bounty programme associated with this repository.

## Reporting a vulnerability

**Please do not report suspected security vulnerabilities in a public issue, pull request, discussion, or commit.**

If GitHub Private Vulnerability Reporting is enabled for this repository, use the repository's **Security** tab and select **Report a vulnerability**.

If that option is unavailable, contact the repository owner through the contact options on the GitHub profile:

https://github.com/ErTapanJatakia

Please provide, where possible:

- A concise description of the suspected issue and its potential impact.
- The affected file, URL, workflow, or configuration.
- Reproduction steps that do not access or expose another person's data.
- Relevant logs or screenshots with secrets, tokens, personal information, and other sensitive data removed.
- A suggested mitigation, if known.

The repository owner may request reasonable clarification to validate and address a report. Please allow time for review before making details public.

## Coordinated disclosure

Please give the repository owner a reasonable opportunity to investigate and address a confirmed issue before publicly disclosing technical details. Do not access, modify, delete, or exfiltrate data; disrupt services; conduct denial-of-service testing; or test third-party systems without explicit authorisation.

Do not include credentials, access tokens, private keys, personal data, or confidential information in public reports.

## Supported status

Security reports are handled on a best-effort basis. This repository does not currently publish formal supported release branches or security-fix timelines. Where a relevant issue is confirmed, remediation may be made directly in the default branch.

## Out of scope

The following are generally outside this repository's control:

- Vulnerabilities in third-party websites, services, badges, images, fonts, or embedded resources linked from the profile.
- Compromise of a third-party account or platform.
- Issues requiring access to systems or infrastructure not maintained by this repository.

Please report third-party issues to the relevant service provider through its own security-reporting process.

Thank you for helping keep this repository and its visitors safe.
