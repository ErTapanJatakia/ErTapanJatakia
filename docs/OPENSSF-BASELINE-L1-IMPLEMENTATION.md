## Evidence and scope guardrails

- This is the official **Baseline Level 1** control set (24 controls), not the OpenSSF Passing/Silver/Gold badge series.
- The source criteria version used is `v2026.08.28`; reassess if the official criteria version changes.
- The active ruleset has a pull-request requirement, branch-deletion protection, no bypass actors and seven required checks. The ruleset is the evidence for primary-branch enforcement.
- The repository is a profile/documentation and automation project. Do not invent application user guides, application dependency manifests, runtime tests, or software build evidence where no application exists.
- A GPG-signed commit/tag is not the same as DCO sign-off or mandatory signed commits.
- The owner-confirmed collaborator permission review is not independent proof of the live collaborator roster or default invitation behavior.
- The repository's security contacts are documented, but the GitHub Private Vulnerability Reporting setting is not independently verified by the connected integration.
- The GitHub Release object is not API-reported as immutable. The signed tag is verified and protected; those are separate properties.
- Unverified controls must not be represented as Met in an external badge submission.

## Reassessment triggers

Reassess when MFA/account-security evidence becomes available, collaborator invitation defaults or roster change, new workflows/inputs are introduced, new official domains/distribution channels are added, software functionality or package manifests are introduced, or the official OpenSSF criteria version changes.
